## What is Live DMX?

Live DMX is a lighting control application built for the heat of the moment. It
patches fixtures quickly, computes DMX at 44 Hz, and talks Art-Net, sACN, OSC,
KiNET and OPC to the rig — with physical USB interfaces when the network is not
an option.

This site has two sections:

- **[User manual](/manual/)** — how to patch, configure and run a show.
- **[Contributing](/contributing/)** — how the codebase is organised and how to change it.
